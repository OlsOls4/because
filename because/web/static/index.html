How it works · what it can answer

What it can answer

  • US SEC filers (Intel, Nvidia, Apple…): revenue, gross margin, operating margin, operating income, net income, by fiscal year.
  • Macro: UK and US inflation and unemployment, by year.
  • Memory: “What do you already know about …?”

How it answers

Scout routes the question and signs a contract for the allowed tools. The analyst runs SQL over public data (SEC EDGAR, ONS, FRED) through Zetaris Lightning, turns rows into findings, tests each candidate cause against explicit thresholds, then scores confidence.

How to check it

Tap any citation chip (F2) to see its source row, query and link. The tabs show every SQL query, the full reasoning trace and what was remembered for next time.
